# Telemetry IVI Client App

This is a sample implementation of a Telemetry Client on IVI to demonstrate the interaction with TelemetryService on IVI.

## How to run

### Startup

1. Set IVI target via `lunch sdv_ivi_cf-trunk_staging-userdebug`
1. Start target via `cvd create`
1. Run `adb root` (required to start Telemetry IVI client)
1. Start Telemetry IVI Agent via `adb shell sdv_ivi_telemetry_service_agent`
1. Push the metrics configuration you would like to run via `adb push <source> <target>` to the device  e.g. `/data/local/tmp`

#### Usage

1. Open the Telemetry Java Client App via the Android UI (on device or via WebRTC link provided at `cvd start`)
1. Load and manage a config a config:
    1. Enter the path to the metrics configuration and click `Load Config`.
    1. Click `Get Configs` to update list of all active and inactive configs.
    1. Select metrics config and use arrows to activate or deactivate configs.
1. Read Report metadata
    1. Go to `Reports` to see generated metrics reports that are generated by TelemetryService.
    1. Click on `Details` to see the detail view shows the report content.
    Note: Currently the report payload cannot be decoded at runtime due to the reflection limitations of the Java Protobuf Lite library.
