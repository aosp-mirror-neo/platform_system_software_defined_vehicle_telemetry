# Sample Vendor Client Application

The sample contains vendor client application which communicates with the telemetry service using
ABI stable C APIs.

### Example usage

1- Run the telemetry service:

```
sdv_telemetry_service
```

2- Run the client:

CPP Client:
```
telemetry_cpp_client
```
Rust Client:
```
telemetry_rust_client
```
